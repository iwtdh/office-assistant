## 📦 安装步骤

### 方式一：手动安装（推荐）
```bash
# 1. 进入插件目录
cd <你的Vault>/.obsidian/plugins/

# 2. 新建文件夹
mkdir lmstudio-office-assistant

# 3. 复制编译产物
cp main.js manifest.json lmstudio-office-assistant/

# 4. 重启 Obsidian → 设置 → 第三方插件 → 启用 "LM Studio本地办公助手"
```

### 方式二：开发模式
```bash
cd obsidian-lmstudio-office
npm install
npm run dev      # 开发模式（监听改动自动打包）
npm run build    # 生产构建
```

## 🔧 配置指南

### 模式 A：LM Studio 本地（默认、推荐）
1. **下载模型**：LM Studio 搜索 `Qwen3.5-9B`（推荐 Q4_K_M / Q5_K_M）
2. **开启服务**：左侧栏 "Local Server" → "Start Server"
3. **参数**：端口 `1234`、Temperature `0.15`、Top-P `0.3`
4. **关键**：系统提示词加入 `禁止输出思考推理内容，不要输出思考块，直接输出答案`

### 模式 B：在线大模型 API
| 设置项 | 示例值 | 说明 |
|--------|--------|------|
| 提供商 | OpenAI / Azure / Custom | 设置面板下拉选择 |
| API Base URL | `https://api.openai.com/v1` | OpenAI 官方；Azure 格式见下；自定义端点填你的域名 |
| API Key | `sk-xxx` / Azure Key | 仅本地保存，不上传 |
| 模型名称 | `gpt-4o-mini` / `deepseek-chat` | 按提供商文档填写 |

**Azure OpenAI 示例**：
```
API Base: https://my-resource.openai.azure.com/openai/deployments/gpt-4o
API Key:  your-azure-key
模型名:   gpt-4o  (需与部署名一致)
```

**国内代理/兼容端点示例**：
```
API Base: https://api.deepseek.com/v1
API Key:  sk-xxx
模型名:   deepseek-chat
```

## 📊 新增任务详解

### 1. 数据规范整理 📊
**适用场景**：Excel 导出的乱码文本、PDF 抽取的表格、API 返回的脏 JSON、手工录入的不规范数据

**输入示例**：
```
张三,男,2024/1/5,10000.5,北京
李四 , 女 , 2024-02-10 , 20000 , 上海
王五,男,2024.03.15,30000.00,广州
赵六,女,2024/4/1,abc,深圳
```

**AI 输出**：
```markdown
## 📊 数据规范化报告

### 1. 原始数据概览
- 记录条数：4
- 字段数：5
- 缺失率：0%
- 异常记录：1 条

### 2. 清洗规则说明
| 字段 | 原始格式 | 目标格式 | 处理逻辑 | 异常处理 |
|------|----------|----------|----------|----------|
| 日期 | 2024/1/5 / 2024.03.15 | 2024-01-05 | 统一分隔符、补零 | 无法解析标记 ⚠️ |
| 金额 | 10000.5 / abc | 10000.50 | 保留2位小数、非数字标记 | ⚠️ 非数字 |

### 3. 规范化数据表
| 姓名 | 性别 | 日期 | 金额 | 城市 |
|------|------|------|------|------|
| 张三 | 男 | 2024-01-05 | 10000.50 | 北京 |
| 李四 | 女 | 2024-02-10 | 20000.00 | 上海 |
| 王五 | 男 | 2024-03-15 | 30000.00 | 广州 |
| 赵六 | 女 | ⚠️ 2024/4/1 | ⚠️ abc | 深圳 |

### 4. 异常记录明细
| 行号 | 原始内容 | 问题描述 | 建议修正 |
|------|----------|----------|----------|
| 4 | 赵六,女,2024/4/1,abc,深圳 | 金额非数字、日期格式不标准 | 金额修正为数字、日期改为 2024-04-01 |

### 5. JSON 导出
\`\`\`json
[
  {"姓名":"张三","性别":"男","日期":"2024-01-05","金额":10000.50,"城市":"北京"},
  {"姓名":"李四","性别":"女","日期":"2024-02-10","金额":20000.00,"城市":"上海"}

\`\`\`
```

## ❓ 常见问题

| 问题 | 解决方案 |
|------|----------|
| 本地连接失败 | 确认 LM Studio Local Server 绿灯亮起，浏览器访问 `http://127.0.0.1:1234/v1/models` 返回 JSON |
| 在线 API 报 401 | 检查 API Key 是否正确、是否有余额/权限 |
| 在线 API 跨域/CORS | 使用支持 CORS 的代理端点，或改用本地模式 |
| 输出被截断 | 调大 Max Tokens（设置页建议 4000-8000） |
| 结果含 `think` | LM Studio 系统提示词加入：`禁止输出思考推理内容...` |
| 右键菜单没出现 | 确认已**选中文本**再右键；或用命令面板 `Ctrl+P` |
| Mermaid 不渲染 | 确认 Obsidian 启用了 Mermaid（设置→编辑器→Mermaid） |
| ECharts 不渲染 | 安装 Obsidian 社区插件 "ECharts" 或 "DataviewJS" |
